Install

Step-by-step install guide
Why the Install button may not appear: browsers only allow installing an app from a web address (https), not from a file opened on your device. Do Part A once, then Part B on each device.

Part A – Put the app online (one time, free)
1. Unzip Marks_App.zip. Keep all 6 files together in the marks folder.
2. Upload that folder to a free host. Easiest: Netlify Drop (app.netlify.com/drop) – drag the marks folder onto the page. Alternative: GitHub Pages – create a repository, upload the 6 files, then in Settings → Pages publish from the main branch.
3. The host gives you a link starting with https://. Open it once while you have internet.

Part B – Install on each device
• Android (Chrome): open the link, tap the green Install app button above (or Chrome menu ⋮ → Install app).
• Windows/Mac (Chrome or Edge): open the link, click Install app above (or the install icon at the right of the address bar).
• iPhone/iPad (Safari): open the link, tap Share → Add to Home Screen.
4. Open the app from its icon. It now works fully offline.

Important: marks are stored on the device where you type them. Use Backup Data regularly, and if you ever change the link, restore your backup in the new one.
Everything below (term, year, subject, teacher, assessments, titles, dates, marks) is saved separately for each class. Remove an assessment with the × in its heading.
Assessment entries accept marks such as 7/10, 18/25 or codes S, A, DNW, N, T. Assessment titles and dates can be edited. The PDF is generated locally by your browser; no internet, account or cloud service is required.
